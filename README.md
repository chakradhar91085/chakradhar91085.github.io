## 🪐 Project constellation

### AegisGraph — Privacy-Aware Graph Intelligence Framework

A Graph-RAG security framework addressing progressive information extraction and subgraph reconstruction risks. Built a controlled retrieval layer using parameterized Cypher queries and a grounded response pipeline with Ollama and Qwen2.5-Coder. Designed an architecture for behavioral risk analysis using query and graph traversal signals.

**Stack:** Python · TypeScript · Vite · FastAPI · Neo4j · Ollama

### Sentinel — AI-Powered Toxicity Detection & Content Moderation

A real-time moderation system using a DistilBERT model fine-tuned on the Jigsaw Toxic Comment Dataset, served through FastAPI with an interactive web interface and confidence-based scoring.

**Stack:** Python · FastAPI · PyTorch · Hugging Face Transformers · JavaScript

### ReachInBox — Asynchronous Email Campaign Scheduling

A campaign scheduling system with staggered delivery, Redis and BullMQ background jobs, per-sender rate limits, retries, idempotency checks, and live email status monitoring.

**Stack:** TypeScript · Vite · Node.js · Express · PostgreSQL · Prisma · Redis · BullMQ · Clerk · SMTP/Ethereal · Docker

[🚀 Live demo](https://outbox-email-scheduler-ten.vercel.app/)
